# Task Automation - CodeAlpha Internship

This is **Task 3** of the CodeAlpha Python Programming Internship.

## 📋 Project Description
A Python script that automatically moves all `.jpg` and `.jpeg` files from one folder to another folder.

## 🛠️ Technologies Used
- Python
- os module
- shutil module

## 🚀 How to Run

1. Create a folder named `source_images`
2. Put some `.jpg` or `.jpeg` photos inside it
3. Run the command:

```bash
python task_automation.py
